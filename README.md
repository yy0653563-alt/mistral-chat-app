# تطبيق محادثة OpenRouter بالعربية

تطبيق ويب عربي من اليمين إلى اليسار، بخادم Node.js وExpress مكتوب بـTypeScript. يستخدم OpenRouter للمحادثة والأسئلة عن الصور، ويقدم توليد الصور عبر Pollinations وميزات صوتية عبر Web Speech API المدمجة في المتصفح.

## المتطلبات والتشغيل

- Node.js 20 أو أحدث.
- مفتاح [OpenRouter](https://openrouter.ai/keys) للمحادثات النصية والأسئلة عن الصور.

```bash
npm install
cp .env.example .env
npm run dev
```

أضف `OPENROUTER_API_KEY` إلى `.env`، ثم افتح [http://localhost:3000](http://localhost:3000). يمكن اختيار النماذج بواسطة `OPENROUTER_MODEL` و`OPENROUTER_VISION_MODEL`، والمنفذ بواسطة `PORT`.

## الأدوات والميزات

تجد أدوات إرفاق الصور وتوليدها والإدخال الصوتي ومسح المحادثة وحفظها في الشريط الجانبي ☰. يمكنك استخدام أمثلة العبارات هناك لتعبئة حقل الرسالة دون إرسالها.

- توليد الصور مجانًا: اضغط 🎨 أو اكتب «ارسم قطة» أو «ولّد صورة لمدينة مستقبلية».
- توليد الأغاني مجانًا: اكتب «ولّد أغنية حزينة عن الفراق». يتطلب مفتاح Acemusic (`ACEMUSIC_API_KEY`).
- الإدخال الصوتي: اضغط 🎤 للإملاء ومراجعة النص قبل إرساله. اضغط 🔊 بجانب رد المساعد لقراءته صوتيًا.
- أصوات قراءة بلهجات عربية متعددة (سورية، مصرية، خليجية، عراقية، وغيرها) مع خيار صوت الهاتف.
- الطقس: «طقس دمشق» أو «حالة الطقس في حلب».
- مواقيت الصلاة: «أوقات الصلاة في دمشق».
- أسعار العملات: «سعر الدولار» أو «أسعار العملات».
- ويكيبيديا: «ويكيبيديا ابن سينا» أو «ابحث في ويكيبيديا عن دمشق».
- قراءة صفحة ويب: أرسل رسالة تحتوي رابطًا مثل «لخّص https://example.com».

الطقس ومواقيت الصلاة وأسعار العملات وويكيبيديا تستخدم خدمات عامة دون مفتاح API. عند إرسال رسالة تحتوي رابط HTTP(S)، يقرأ التطبيق صفحات HTML العامة فقط ويطلب من النموذج تلخيص محتواها. إرفاق صورة يجعل الرسالة سؤالًا بصريًا ولا يشغّل أدوات الرسائل النصية.

## البناء وفحص الأنواع

```bash
npm run typecheck
npm run build
npm start
```

تقبل `POST /api/chat` رسالة `message`، وسجلًا اختياريًا `history`، وصورة اختيارية بصيغة data URL. يمكن إرسال `imageRequest: true` لطلب توليد صورة. سجل المحادثة يقتصر على آخر 20 رسالة، وحد الرسالة 8000 حرف، وحد وصف الصورة 500 حرف. مهلة الخادم لطلبات OpenRouter 60 ثانية، ومهلة العميل 90 ثانية.

## النشر على Render

استخدم **Build Command** `npm run build` و**Start Command** `npm start`، واضبط `OPENROUTER_API_KEY` و`ACEMUSIC_API_KEY` (لتوليد الأغاني) ومتغير `PORT` الذي يحدده Render تلقائيًا.
